Privacy Policy

Last updated 23 November 2026

GTA Vice Hours Uploader (the "tool") is an in-house tool run by the owner of the YouTube channel GTA Vice Hours. It uses YouTube API Services. This policy explains what the tool accesses through those services, and what it does with it.

YouTube API Services and Google's Privacy Policy

The tool uses YouTube API Services. By using the tool, you are also bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

Whose data

The tool has one user: the channel's owner. It signs in with Google (OAuth 2.0) only to the GTA Vice Hours channel's own account. It does not let anyone else sign in, and it does not collect data about viewers or other YouTube users.

What the tool accesses

  • Uploading (scope youtube.upload): it uploads the channel's own edited videos, with their title, description and tags.
  • Reading (scope youtube.readonly): it reads public statistics (view, like and comment counts) of the channel's own videos, and the channel's subscriber and video counts.

It does not read comments, messages, viewer identities, watch history or any other channel's private data.

How the data is used, stored and shared

  • Video statistics are used only to judge which clips perform well, and to report views to the clipping campaigns that sponsor the clips. Those campaigns see the public video links and public view counts.
  • Statistics are stored in a file on the owner's own computer and refreshed at most once an hour. The OAuth token is stored on that computer only. Neither is sold or shared with anyone else.
  • The tool uses no cookies or tracking, and serves no advertising.

Keeping and deleting data

Statistics held by the tool are replaced at each refresh. They are deleted within 30 days of the tool stopping use of YouTube API Services, or of access being revoked. Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the tool deletes its stored token and the statistics it holds.

Changes and contact

Changes to this policy are published on this page, with a new date. For questions or deletion requests, open an issue at github.com/DJ-a11/gtavicehours/issues.
